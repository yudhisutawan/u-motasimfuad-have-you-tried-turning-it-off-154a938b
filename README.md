## The line

> Your ticket has been escalated to our highest tier. That's me. I'm the highest tier. Please hold.

(97 characters — under the 200-character gate.)

## How it works

`main.py` is stdlib-only. It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -S -P main.py
cat /tmp/out/entry.txt
```
